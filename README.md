# Cat Personality Quiz

Take this quiz to determine which cat personality you have: Starry, Mittens, or Bijou. 

This project is built using React + Vite. 

## Local Development Instructions

1. Clone the repo into Visual Studio Code or your IDE of choice.
2. Open a terminal and run ```npm install``` to generate node_modules.
3. Run ```npm run dev``` to start the local development server.
4. Navigate to http://localhost:5173 to view your local changes.

## Build and Deploy Instructions

1. Run ```npm run build``` to build the project.
2. Run ```npm run deploy``` to deploy the dist folder to the gh-pages branch.
3. Navigate to http://maryeprouty.github.io/cat-quiz to view the published website.
